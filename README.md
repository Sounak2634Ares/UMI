### UMI - Smart Time, Holiday & Math AI Assistant

UMI is a versatile AI assistant designed to handle time tracking, Indian public holiday lookups, and mathematical problem-solving. Whether you need to know the current date, plan around upcoming holidays, or solve complex algebraic equations, UMI has you covered. 

### 🚀 Features

* **Temporal Awareness:** Instantly provides the current time, day, date, month, and year.
* **Indian Holiday Tracker:** Fetches current Indian public holidays and forecasts upcoming festival dates.
* **Mathematical Engine:** Solves arithmetic calculations and complex algebraic problems.

### 🛠️ Installation

Clone the repository and install the dependencies: 

git clone https://github.com/yourusername/umi-ai.git
cd umi-ai
pip install -r requirements.txt

### 💻 Usage

Run the main application file to start interacting with UMI: 

python main.py

### Example Commands

* **Time:** "What day of the week is it today?" or "Current time status"
* **Holidays:** "Is it a public holiday in India today?" or "List upcoming holiday"
* **Math:** "Solve 2*x + 5 = 15" or "Calculate 456 * 78"
